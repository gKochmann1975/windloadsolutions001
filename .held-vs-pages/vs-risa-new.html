The three gaps that matter for a permit set

From RISA's own docs and product pages — not invented weaknesses.

Code edition

RISACalc wind stops at 7-16

RISA's help docs and RISACalc v4.2 release notes list a wind generator that supports ASCE 7-10 and 7-16 only — no 7-22 path. We run 7-22 directly, so pressures match what a 2026 reviewer expects.

The seal

RISA stamps nothing, anywhere

RISA-3D and RISACalc are software-only. No sign-and-seal in any state, per their product pages. We pair the calc with a real licensed-PE seal — in-house Florida P.E. for FL, a partner-PE network elsewhere.

Jurisdiction

Raw map value vs enforceable value

A generator that returns the bare ASCE map number leaves the code step to you. We auto-apply Florida Building Code 8th Ed. (2023) HVHZ values — the enforceable numbers a plan reviewer checks against.

Who should pick RISA-3D

Honest recommendation

Need full FEA and multi-material design — steel, concrete, wood, masonry, aluminum, cold-formed, not just wind? Pick RISA-3D. Its analysis engine is a real workhorse, and on the structural side it carries current standards like ASCE 7-22 and AISC 360-22.

WindLoadCalc doesn't do general FEA or member design, and won't pretend to. For many offices the honest answer is both: RISA-3D for the model, WindLoadCalc for the current-code wind loads and the sealed deliverable.

Frequently asked questions

Can RISACalc produce an ASCE 7-22 wind result?

Not according to RISA's own documentation. The RISACalc wind/seismic load generator supports ASCE 7-10 and ASCE 7-16 only, per RISA's help docs and the v4.2 release notes — it has no ASCE 7-22 wind option. WindLoadCalc runs ASCE 7-22 directly (and 7-16 when a project still calls for it), so you are pulling pressures from the edition the reviewer expects on a 2026 permit set.

Does RISA stamp or seal drawings?

No. RISA-3D and RISACalc are software tools; nothing in their product pages offers a licensed-PE sign-and-seal deliverable in any state. WindLoadCalc pairs the calculation with an actual sealing service — an in-house Florida P.E. for FL work and a partner-PE network for the other states — so calculate and seal happen in one workflow.

I already own RISA-3D — why add a separate wind tool?

Keep RISA-3D for the finite-element analysis and member design it does well. The wind generator bundled inside the RISA stack is a secondary feature that tops out at ASCE 7-16, outputs the raw map value with no Florida HVHZ override, and produces no per-coefficient citations or AutoCAD-ready schedule. Use WindLoadCalc for the current-code wind numbers and the sealed, permit-ready deliverable, then carry the loads back into RISA-3D for your structural model.

Does WindLoadCalc do full 3D structural analysis like RISA-3D?

No, and it is not trying to. RISA-3D is a genuine finite-element structural-analysis and multi-material design suite (steel, concrete, wood, masonry, aluminum, cold-formed). WindLoadCalc is a dedicated wind-load specialist that produces the design pressures, certifications, and reports — it does not replace a general FEA engine. The two are complementary, not competing for the same job.

What does WindLoadCalc cost compared with RISA?

WindLoadCalc plans start at $35/month with a 7-day free trial and no credit card, and everything runs in the browser. Published third-party figures put RISACalc near $1,000/year and RISA-3D roughly $2,070–$2,290/year per license (exact figures unverified); RISA-3D is also a Windows desktop install you have to manage. You can confirm WindLoadCalc's output against your RISA numbers using the free public tool before paying anything.

How does WindLoadCalc handle Florida HVHZ wind speeds?

It auto-applies the Florida Building Code 8th Edition (2023) HVHZ overrides — for example, Miami-Dade's legally enforceable 175 mph value under FBC R301.2(7) — instead of just echoing the raw ASCE 7-22 map number. A wind generator that returns only the map result, like the one inside the RISA stack, leaves that jurisdictional step to you.
