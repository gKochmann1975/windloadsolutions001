3Velocity Pressure Calculation

Velocity pressure at mean roof height per Eq. 26.10-1:

Eq. 26.10-1 qh = 0.00256 · Kz · Kzt · Kd · Ke · V2

3.1 Velocity Pressure Exposure Coefficient, Kz

ASCE 7-22 §26.10.1 · Eq. 26.10-2 · Table 26.10-1

Eq. 26.10-2 Kz = 2.41 · (z / zg)2/α  for z ≥ zmin
Kz = 2.41 · (zmin / zg)2/α  for z < zmin
Exposure C terrain constants (Table 26.11-1):
α = 9.8 · zg = 2460 ft · zmin = 15 ft
z = h = 36.63 ft

For z ≥ zmin:
Kz = 2.41 × (36.63 / 2460)2/9.8
Kz = 1.0198

3.2 Topographic Factor, Kzt

ASCE 7-22 §26.8 · Eq. 26.8-1 · Table 26.8-1

Eq. 26.8-1 Kzt = (1 + K1 · K2 · K3)2
Topographic feature: Flat terrain — topographic effects do not apply (Section 26.8.1).
K1 = 0 · K2 = 0 · K3 = 0
Kzt = (1 + 0)2 = 1.0000

ASCE 7-22 §26.9 · Eq. 26.9-1 · Table 26.9-1

Eq. 26.9-1 Ke = e(−0.0000362 · ze)
Site ze = 0 ft:
Ke = e(−0.0000362 × 0) = 1.0000
