# State Building Code → ASCE 7 Edition — Adoption Status
*Which ASCE 7 edition each state's building code currently references, and when the next update is
expected. Accurate **as of 2026‑06‑27**.*

> ⚠️ **Verify before relying on a specific date.** Building‑code adoption dates shift frequently
> (North Carolina alone has been delayed several times). Re‑confirm the specific state from the
> authoritative source immediately before quoting a date/edition on anything customer‑facing.
> This is reference background, not a live feed.

**Code → ASCE rule of thumb:** 2018 IBC → ASCE 7‑10/‑16 · 2021 IBC → ASCE 7‑16 · 2024 IBC → ASCE 7‑22.
*(Verify per state — some states amend the referenced standard.)*

| State | Current code in force | ASCE 7 (current) | Next edition & timing | ASCE 7 (next) |
|---|---|---|---|---|
| **CA** | 2025 Title 24 / CA Building Standards Code — **effective Jan 1 2026** (2024‑IBC based) | **7‑22** | Residential frozen by **AB 130 until ~2031**; non‑residential next cycle ~2028 | 7‑22 |
| **VA** | 2021 USBC — mandatory since Jan 18 2025 | 7‑16 | 2024 cycle underway (proposals 2025) → likely effective **~2027** | 7‑22 |

| **SC** | 2021 SC Building Code — effective Jan 1 2023 | 7‑16 | 2024 cycle in progress (notice Jan 2025) → likely **2026–2027** | 7‑22 |
| **NC** | **2018 NC State Building Code** still in force (2024 repeatedly delayed) | 7‑10 | 2024 code delayed indefinitely — earliest **Jan 1 2027**, unconfirmed (usable now as an *alternative method*) | 7‑22 |
| **HI** | 2018 IBC State Building Code (adopted Apr 2021) | 7‑16 | Behind cycle, politically fast‑tracked (2025 emergency proclamation) — no firm date | 7‑22 (expected) |
| **TX** | **No statewide edition mandate** — state sets a minimum; cities adopt + amend (many on 2021, Austin on 2024) | 7‑16 (mostly) | **No statewide schedule** — jurisdiction‑by‑jurisdiction | varies |

---

## Notes
- **CA is the outlier (ahead):** the only state already on a 2024‑IBC‑based edition (**ASCE 7‑22**),
  effective Jan 1 2026 — but AB 130 freezes *residential* code updates until ~2031.
- **VA, LA, SC** are mid‑cycle, moving 2021 → 2024 I‑Codes (**ASCE 7‑16 → ASCE 7‑22**) over the next ~1–2 years.
- **NC and HI lag:** NC still on 2018 (**ASCE 7‑10**) with the 2024 edition stuck; HI on 2018, being fast‑tracked.
- **TX has no single answer** — the applicable edition depends on the specific city/county
  (the TWIA coastal windstorm overlay is a separate matter).
- Note that many states sit **1–3 editions behind** the current ASCE 7‑22.
