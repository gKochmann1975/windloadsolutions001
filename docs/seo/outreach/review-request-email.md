**Purpose:** G2 and Capterra rankings are review-driven, and customer reviews are one of
the top sources AI engines cite when answering "best wind load software." This is the
email to ask **genuinely happy, paying subscribers** for an **honest** review.

## Rules (do not break — Hard rule #1 territory)
- Only send to real, active paying customers who've had a good experience.
- **Never pay for or incentivize a _positive_ review.** It violates G2's policy and our
  own no-fake-social-proof rule. Asking for an *honest* review (any sentiment) is fine.
  If you want a compliant incentive, use **G2's own review-collection campaign** — G2
  handles the gift-card mechanics so the vendor never ties a reward to a positive rating.
- Send individually or via mail-merge — never a visible mass-BCC. It should feel personal.
- **Send only after the G2 profile is claimed and you have the review link** (the
  `{{G2_REVIEW_LINK}}` below).
