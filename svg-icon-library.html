House inline-icon spec (match this for every new icon): viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round". Set the size with width/height and the color on the parent via color: (icons use stroke="currentColor"). Add aria-hidden="true" when the icon is decorative next to text.
